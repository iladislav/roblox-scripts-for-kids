# Roblox Scripts for Kids

Beginner-friendly **Roblox Studio (Lua) scripts** for kids and teens aged 8–17 who are making their first Roblox games. Every script is short, commented line by line, and ready to paste into Roblox Studio.

Made by the mentors of **[Excklusive-IT](https://en.excklusiveit.com/)**, a coding school for kids with live 1-on-1 online classes in Roblox game development, Python, web development and chess.

## Scripts

| Script | What it does | Where to put it |
|---|---|---|
| [`KillBrick.lua`](KillBrick.lua) | A part that resets the player on touch (lava, spikes) | Script inside a Part |
| [`Door.lua`](Door.lua) | A door that opens when you click it and closes after 3 seconds | Script inside a Part with a ClickDetector |
| [`MovingPlatform.lua`](MovingPlatform.lua) | A platform that moves back and forth smoothly | Script inside an anchored Part |
| [`Teleport.lua`](Teleport.lua) | Step on one pad, appear on another | Script inside the first pad |
| [`Leaderboard.lua`](Leaderboard.lua) | Shows Coins for every player and adds 1 coin every 10 seconds | Script in ServerScriptService |
| [`CoinPickup.lua`](CoinPickup.lua) | A coin that gives +1 and respawns | Script inside a coin Part |

## How to use a script

1. Open **Roblox Studio** and your place.
2. In the **Explorer**, hover over the object from the table (for example a Part) and click **+** → **Script**.
3. Delete the default `print("Hello world!")` line and paste the script.
4. Press **Play** (F5) to test.
